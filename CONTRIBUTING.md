# Contributing

Thanks for helping grow **Awesome MegaKernel**.

## What to add

- Research papers on megakernels / persistent kernels / end-to-end fused LLM kernels
- Open-source megakernel implementations, compilers, and serving systems
- High-quality surveys, blogs, or tutorials that explain megakernel design

## How to add

1. Fork the repo and open a PR against `main`.
2. Prefer adding entries to both `README.md` (English) and `README.zh-CN.md` (Chinese).
3. Keep table columns consistent: Title · Venue · Date · Code · Authors · Topics.
4. Prefer arXiv / official paper links and official GitHub repos.
5. One PR ≈ one theme (e.g. a paper + its code), with a short note on why it belongs.

## Style

- Newest papers first within each section.
- Use topic tags like `` `CUDA` `` `` `MoE` `` `` `Compiler` `` `` `Agent` ``.
- Do not add unmaintained forks or closed-source-only marketing pages unless they are the primary artifact.
